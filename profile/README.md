Cards for your README: contribution stats, top languages, pinned repositories, gists and WakaTime coding time rendered as SVG.

The usual way to get one is an image URL pointing at somebody's hosted instance.
That instance serves everyone out of one shared pool of GitHub tokens,
so a busy day rate-limits every user at once and your README shows a broken image.
Nothing here is hosted.
You render the card where you already have a token:
in a GitHub Actions run that commits the SVG, in your own endpoint, or from your terminal.
The file keeps working even if every instance goes away.

## Where this comes from

This is a fork, and the work is not ours alone.
It continues [**stats-organization/github-stats-extended**](https://github.com/stats-organization/github-stats-extended),
which is itself based on [**anuraghazra/github-readme-stats**](https://github.com/anuraghazra/github-readme-stats).
the project that made these cards a thing in the first place.
